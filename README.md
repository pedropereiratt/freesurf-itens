# freesurf-itens

Ícones dos itens do FreeSurf no Steam Inventory Service.

A Steam não hospeda a imagem de um item: o `itens-da-loja.json` do jogo aponta
para estes arquivos, e ela baixa e guarda uma cópia. **Não apague nem renomeie**
um ícone de skin que já está à venda.

| Arquivo | Skin |
| --- | --- |
| `100.png` / `100_grande.png` | Esqueleto |
| `101.png` / `101_grande.png` | Astronauta |
| `102.png` / `102_grande.png` | Zumbi |

`<número>.png` tem 200 × 200 e `<número>_grande.png` tem 1024 × 1024. O número é
o `ITEM` do `.txt` da skin. Os arquivos saem de `Tools/Steam/inventario/icones`
no projeto do jogo.
